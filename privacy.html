Privacy

What this site does with your data, in plain words.

Short version

This site has no accounts, no ads and no tracking across other sites. The only thing it saves on your device is your light or dark choice.

Things that involve other companies

Fonts load from Google Fonts, so Google sees your IP address when a page loads. The About page asks GitHub’s public API for my repositories, so GitHub sees your IP address too. The site is hosted on GitHub Pages, which keeps normal server logs.

Languages

If you pick a language, Google Translate’s script loads and sets a cookie that remembers your choice. Google handles that under its own privacy policy. If you never use the language menu, none of this happens.

Visit counts

If I switch on analytics, it will be GoatCounter, which counts visits without cookies. I will update this page if that changes.
